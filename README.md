# bubble-sort-temperaturas
Projeto em C para ordenação de temperaturas utilizando o algoritmo Bubble Sort.

# Bubble Sort — Ordenação de Temperaturas

## 1. Sobre o projeto

Este projeto foi desenvolvido para a atividade avaliativa da disciplina **Algoritmos e Pensamento Computacional**, do Centro Universitário UDF.

O programa foi criado na linguagem C e utiliza o algoritmo Bubble Sort para organizar 10 temperaturas em ordem crescente.

## 2. Objetivo

O objetivo é praticar o uso de vetores, estruturas de repetição, estruturas condicionais e troca de elementos em um algoritmo de ordenação.

## 3. Como funciona

O programa solicita ao usuário 10 temperaturas e apresenta os valores digitados antes da ordenação.

Em seguida, utiliza o algoritmo Bubble Sort para comparar elementos vizinhos do vetor. Quando um elemento é maior que o próximo, os dois trocam de posição.

Esse processo se repete até que todas as temperaturas estejam organizadas em ordem crescente, da menor para a maior.

Ao final, o programa exibe as temperaturas ordenadas.

## 4. Tecnologias utilizadas

- Linguagem de programação C.
- OnlineGDB para escrever e testar o código.
- GitHub para armazenar e documentar o projeto.

## 5. Como executar

1. Abra o arquivo `bubble_sort.c` em um compilador C.
2. Compile e execute o programa.
3. Digite as 10 temperaturas solicitadas.
4. Confira os valores originais e o resultado ordenado.

Também é possível compilar pelo terminal, utilizando o GCC:

```bash
gcc bubble_sort.c -o bubble_sort
```

No Windows, execute o programa com:

```bash
bubble_sort.exe
```

## 6. Exemplo de execução

**Temperaturas digitadas:**

32, 25, 29, 21, 30, 18, 27, 24, 35, 20.

**Resultado em ordem crescente:**

18, 20, 21, 24, 25, 27, 29, 30, 32, 35.

## 7. Conteúdos aplicados

- Vetores.
- Estruturas de repetição `for`.
- Estrutura condicional `if`.
- Comparação de elementos vizinhos.
- Troca de valores utilizando uma variável temporária.
- Algoritmo de ordenação Bubble Sort.
